## 可先执行的简版结论

建议候选：**固定 TRAIN-PCA 参考值 + 稀疏、低容量的独立 age/sex/site 关系学习**。

保留同一 798 个 TRAIN acquisition 参考；训练集上一次性拟合 PCA32，query 与 reference 共用且冻结；当前患者 FC 只能进入 pair scorer，不能进入 value/output。每个关系各自学习有界对角 FC 距离与小型 metadata scorer，在全部允许 reference 上算分后保留 top-32；聚合固定 reference PCA 值，并减去允许 reference 的均值。三个关系用全局可学习权重融合，经共享 rank-8 输出与有界残差加入原 BP fused representation。

删除旧 M3 的 `fc_projection:6670→32` 可训练层、`values(current)`、`query_projection(h)`、患者相关 `gate(h)`、三个独立 value 网络及 M3 LayerNorm；不改 BP trunk、legacy population、分类器或损失。

- Candidate：M3 V3，Fixed-PCA Sparse Multi-Relation Reference Readout。
- Problem：旧模块表现主要来自直接 current-FC 值路径，注意力接近均匀；增加高维可训练 FC 投影容量导致明显训练/验证差距。
- Core：train-only 固定数值 FC 基底和固定参考值；关系学习只改变 query→TRAIN 的稀疏权重；禁止直接 query value。
- Closest BrainPromptPlus：§III-C Eq. (5)–(7) subject-prompted population graph。
- Similarity：**Medium**。
- Does it reproduce a BrainPromptPlus novelty：**NO，限本文精确定义**。

## 2. 输入与一次性 TRAIN-only 固定变换

约定 `N=798`，AAL116 无对角上三角 FC 向量 `x_i∈R^6670`；固定参考集 `R` 与已有 TRAIN membership/顺序完全相同。标签、diagnosis、Source_Dataset、subject/session ID 均不进入数值特征、score、value、gate 或 PCA。ID 只用于 self-reference mask 和审计。

仅使用 TRAIN FC，计算：

```text
mu = mean_{j∈R} x_j
C  = (X_R - mu)^T (X_R - mu) / (N - 1)
U32, lambda32 = C 的最大 32 个特征向量/特征值
eps_pca = max(1e-8, 1e-4 * lambda_1)
z(x) = ((x - mu) U32) / sqrt(lambda32 + eps_pca)
t(x) = z(x) / max(||z(x)||_2, 1e-6)
k_j = stop_gradient(t(x_j))
q_i = stop_gradient(t(x_i))
```

使用 float64 拟合后存 float32 buffers；PCA 不随机抽样、不加监督目标、不用 validation/test 拟合均值、方差、方向或参考筛选。可用对 `798×6670` 中心化矩阵的确定性 full-SVD，或 `798×798` Gram 特征分解回投影；不要显式分配完整 `6670×6670` covariance。每列最大绝对 loading 的符号固定为正，以便确定性保存。要求有至少 32 个非退化方向，否则停止并报告；不能悄悄借入 validation 样本。

缓存 `mu/U32/lambda32/k_R/reference_metadata/reference_ids`，保存 TRAIN ID checksum、输入 FC checksum 与 PCA checksum；`requires_grad=False`。对同一划分不同训练 seed 复用完全相同 PCA。只有数值 FC PCA，无频谱/空间语言 prompt。

TRAIN query 的允许集合 `P_i=R\{same acquisition ID}`，validation/test query 为 `P_i=R`。调用必须提供 acquisition IDs；不允许根据标签选择 reference，不随机 reference 子采样，不缓存由训练状态持续变化的 reference encoder。

## 3. 三个独立可学习关系：确切公式

关系 `r∈{age,sex,site}` 各自拥有参数 `theta_r∈R^32`、独立 `g_r` 和温度标量 `eta_r`，不共享 scorer 参数：

```text
w_r = 1 + 0.5 * tanh(theta_r)             # 每维范围 (0.5, 1.5)，初值 1
d^r_ij = sum_l w_rl * (q_il - k_jl)^2
tau_r = 0.25 + 0.75 * sigmoid(eta_r)      # 初始 tau=0.5
b^r_ij = 0.5 * tanh(g_r(phi^r_ij))       # 有界 metadata 修正
s^r_ij = -d^r_ij / tau_r + b^r_ij
```

这里 `g_r = Linear(p_r,8) → GELU → Linear(8,1)`，没有 embedding lookup、reference-specific bias 或 ID 参数；线性层用小随机初始化，最后一层不全置零，以保证首次反传 scorer 全部可获梯度。

metadata 特征只读既有 train-fitted `MetadataEncoder` 输出：

- **age**：令标准化年龄差 `Delta=clip(|a_i-a_j|,0,4)`，`phi_age=[Delta, Delta²/4, clip((a_i+a_j)/2,-3,3)]`。标准化均值/方差仍只来自 TRAIN。缺失或非有限 age 按现有数据合同报错。
- **sex**：`phi_sex=[both_F,both_M,one_F_one_M,any_unknown]`，unordered pair；不把数字类别编码当连续变量。
- **site**：`phi_site=[same_known_site,different_known_sites,any_unknown]`。只使用已核验的 acquisition site；unknown 不等于 same-site，不用 Source_Dataset 代替 site。这个保守版本学习真实 site 同/异关系，不学习特定 site 的查表偏置。

FC 对角距离在三个关系里独立学习；三个 metadata MLP 的参数、输入含义、温度均独立。不强制“同 sex/site 必须更近”或“相近年龄一定同病”，由训练任务决定有界修正。site 没有患者级或站点级标签记忆表。

## 4. 稀疏 attention 与无 query-value 的参考读出

每个 query/关系仍对全部 798 个 TRAIN reference 计算分数。先 self-mask，再进行 deterministic top-32：

```text
S_ir = TopK_32({s^r_ij : j in P_i})
alpha^r_ij = exp(s^r_ij) / sum_{l∈S_ir} exp(s^r_il)  if j∈S_ir else 0
u_ij = 1 / |P_i| if j∈P_i else 0
m_ir = sum_j (alpha^r_ij - u_ij) * k_j
```

top-k ties 使用固定 reference 顺序稳定处理，不用 ID 数值加到 score；`K=32` 在本版本固定，不按 validation 表现来回扩大搜索。top-k index selection 是离散操作，不能声称它处处可微；active support 内的 score/softmax/scorer 是可微的，支持随更新改变。

`m_ir` 只聚合冻结 TRAIN reference values。`q_i` 仅用于算边分数，严禁出现 `W(q_i)`、`-W(q_i)`、`concat(m_ir,q_i)` 或 `W(h_i)` 作为人口图输出；不得增加可训练 per-reference value/bias。TRAIN 留一参考均值由其余允许 reference 求得，不能用当前 query FC 来补算。这样把全部 attention 换成允许集上的 uniform 时，人口图消息严格为零；均匀全库均值不再经关系输出变成恒定可训练偏置。

这仍可能经数据相似性检索保留患者特征；它限制的是显式 value shortcut 与高维自由参数，不保证消除所有监督过拟合。是否从其他人的关系得到有用信息仍需下面的 retrained controls。

## 5. 低容量融合与输出幅度

使用**全局可学习**关系权重（没有 `gate(h_i)`）：

```text
pi = softmax(beta)                         # beta∈R^3，初始均匀
m_i = sum_r pi_r * m_ir                    # 32维
u_i = W_out Dropout_0.2(W_bottleneck m_i)   # W_bottleneck:32→8, W_out:8→d
gamma = 2 * sigmoid(gamma_raw)             # 初始 gamma=0.1
delta_i = gamma * u_i / sqrt(1 + ||u_i||²) # ||delta_i|| < 2
fused_i = unchanged_BP_fused_i + delta_i
```

两个输出层无 bias，用小的非零随机初始化；没有额外 LayerNorm，避免把微小消息无条件放大。每个患者独立做 norm/squash；Dropout 仅训练使用，eval 关闭。保留原有分类 CE、疾病文本辅助 CE、class weights、optimizer/scheduler/early stopping 合同，不能同时改 loss 把效果归因混在一起。

`gamma` 有界是针对旧 residual 范数 19 vs subject 7 的容量约束，不能以其上界断言效果最优。此版上界 2、rank8、dropout0.2 均预先固定；若训练明确显示饱和/欠拟合，再作为下一轮具体变体重审和登记，不读取 test 调参。

M3 新增可训练参数数量约为 `3*32 + 3 temperatures + (41+49+41) metadata MLP + 3 relation weights + 32*8 + 8*d + 1 gain = 490+8*d`。其中 age/site MLP 各41、sex MLP49；避免旧 213440 个 FC projection 参数。PCA buffers 不计可训练参数。这个候选的容量降低来自具体参数化和输入限制，普通 dropout/PCA 本身不是新科学贡献。

## 6. 与 Plus 的逐项比较与审查决定

**Candidate：** M3 V3 fixed-PCA sparse multi-relation TRAIN-reference readout，限定 §2–5 的输入、公式和信息流。

**Problem addressed：** 避免高维当前 FC 直连值路径使“人口关系”退化成患者分类 MLP；限制小样本过拟合；消除 reference 平均消息的常量路径；保留可学习 age/sex/site 关系及推理 batch independence。

**Core mechanism：** TRAIN-only frozen PCA key/value bank；独立有界 relation metric 与 metadata scorer；query→reference top-k softmax；reference-only centered message；全局 relation fusion 与低秩有界 residual。

**Closest BrainPromptPlus component：** §III-C Eq. (5)–(7)。Plus 在当前 batch 计算脑图表示相似度与单个 subject-text 相似度，乘积阈值化成一个 population adjacency，再 GCN；本候选不构造 query-query 边、不把 age/sex/site 混为同一个 subject-text scorer、不用 thresholded product，不用可训练 reference FC encoder。

**Similarity：Medium。** 同属 population 信息与 demographics 融合；具体训练参考库、关系参数化、value限制、稀疏权重与信息流不同。

**Does it reproduce a BrainPromptPlus novelty：NO。**

**Decision：ALLOW for implementation and controlled validation。** 这只放行本文的 V3，不自动放行任何之后添加 spectral/spatial 文本、站点 embedding lookup 或 query-value 的变体。

| Exclusion / inherited component | V3 的具体区别 |

## 7. 编码后必须验证的合同、诊断和对照

### 合同与实现验证

1. PCA fit/reference membership 正好为同一 798 TRAIN acquisition；mu/U/lambda/k 无梯度；无 validation/test/reference-label/source 路径；self-attention 精确为0。
2. 全模型 eval 的 batch size 1/7/20/100、不同顺序和不同同伴下，同一 acquisition logits 最大差应≤`1e-5`，记录实际差值。不能只检测 M3 子模块；若硬件精度有合理差异，报告而不静默放宽。
3. M3 中所有依赖 query FC 的路径只到 scorer；`autograd` 与参数清单确认不存在 `6670→32` trainable projection、per-reference table、current-value 或 h-gate。
4. 每个关系 nnz≤32、row-sum≈1、all finite；分别记录 θ/metadata-MLP/temperature/fusion/output 的梯度。初始化不能因整个输出路径置零让 scorer 永久无梯度。
5. 将 alpha 全部改成允许参考集 uniform，`m` 和 `delta` 应数值为0；这是结构合同，**不作为学习有效性的证据**。

### 必须保存的训练/validation 诊断

三 seed 使用同样 validation selection；记录 train-vs-val macro-F1、attention top32支持重叠率、support内归一化熵 `H/log32` 和全库熵 `H/log|P_i|`、effective-neighbors、top1 mass、metadata修正分布、三关系m余弦、pi、gamma、residual/trunk范数比。**top-k本身会降低全库归一化熵，不能拿它作为学会关系的证据。**

### 最少的 retrained controls / sensitivity

- **BP_control**：原样保持，回答整个 V3 是否改善验证集表现；不改其类权重或预算。
- **Frozen relation control**：冻结 θ=0、g=0、tau=.5、pi均匀，只训练同样的低秩输出/gain与BP trunk，仍使用相同 PCA、top32、centered reference。回答 learned relations 是否优于固定 FC 最近邻检索。
- **Metadata-off control**：只令三个 `b^r=0`，其余可训练，回答 metadata 是否提供增益；该对照仍有独立 FC metric。
- **Matched PCA-direct control（明确只作对照，不能并入V3）**：把当前 query 的固定 `q_i` 输入同样 rank8/output/gain，参数量和 norm cap相同；回答参考关系是否优于低维 FC 直接表征。它故意包含 direct value，不能与 V3 本体混称。
- 对已训练 V3 做敏感性：在 learned support 内改为uniform、冻结/打乱 metadata score、逐关系置零、打乱 reference value 与key对应。记录probability变化和macro指标；这些不是 retrained ablation，不单独证明因果机制。

不以“强制稀疏”“梯度非零”“去掉整体残差改变预测”判定 M3 有效。若 V3不优于固定关系或 PCA-direct、关系仍近似等同、train-val差距仍大，应报告该候选尚不支持人口关系增益，不能仅因运行完成入选最终三个模块。
