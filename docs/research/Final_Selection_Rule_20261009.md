# Final promotion and reporting rule, before final interactions/test

The stage2 protocol five-metric categories remain unchanged. The original BrainPrompt three-seed mean is the primary baseline; BP_control is reported separately and must not be substituted merely because it is lower. Checkpoints remain selected within each run by validation macro F1, then the fixed composite, then lower loss. No test results exist at this declaration.

After the finite registered development matrix is complete:
1. Rank non-control candidate configurations by category Strong first, then Acceptable; within a category use mean validation macro F1, then the existing mean composite, then fewer trainable parameters. Mixed/Weak configurations are retained in result tables but do not pass this promotion rule.
2. A three-module system is accepted as Top-3 only if it also has positive mean macro-F1 marginal contribution from each module in the complete eight-way ablation, no clear unresolved mechanism bypass/degeneration, and individually documented BP/Plus differences. Generic readouts and ordinary training/initialization changes are not automatically new scientific contributions. Small noisy gains do not establish statistical or clinical generalization.
3. If no triple meets these requirements, explicitly report NO QUALIFIED TOP-3. Do not force a weak third module. The best eligible simpler candidate may be delivered as a conservative experimental configuration, labeled with its actual module count and remaining limitations. If none is eligible, retain BrainPrompt as the reference and report the unsuccessful search.
4. Freeze the selected experimental configuration, the leading fully evaluated triple used for the complete ablation report, all three seeds/checkpoint hashes, and the test evaluation set before any test loader is created. Choose that illustrative triple by the same category/macro-F1/composite ordering among completed triples, and never by test results. Its use in an ablation table does not imply acceptance as final innovations.
5. Test the frozen baseline models (original BP, legacy Pro, historical stable Pro), the frozen selected configuration, and the eight configurations of the frozen illustrative ablation family, using the same holdout/probability metrics. Preserve the official BP and BP_control as distinct repeated runs. Every tested model uses all three seeds. No architecture, hyperparameter, selection, or checkpoint changes after test access; no switch to another model because it wins on test.
6. Report five metric means and sample SD, per-seed and per-class results, prediction distributions, by-source diagnostics, complete ablation marginals, provenance and all failed targets. Test samples are the same 100 acquisitions across seeds, not 300 independent patients. ADNI1–4 have historical exploratory exposure; this is not a new external cohort. Scan-level subject overlap is allowed by the user protocol and explicitly described.

The last development scope is the two conditional hypotheses in Final_Interaction_Pairs_Plan_20261009.md. No additional model/initialization/loss search will be opened merely to pursue a desired score. If the empirically required Top-3 or 60% macro targets are not met, report that factual negative result rather than inventing performance or labeling unrelated modules as successful innovations.
